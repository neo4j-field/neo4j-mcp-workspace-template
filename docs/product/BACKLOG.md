# Product backlog

Purpose: help SEs quickly build useful graphs from structured/unstructured data and
reuse readable code in customer POCs. Correctness, clear failure and easy setup
come first. This is not a production pipeline roadmap.

Statuses: `proposed`, `accepted`, `deferred`, `in-progress`, `implemented; release smoke pending`, `done`, `declined`.
Groups below replace the previous P0/P1/P2/P3 release commitments. Existing IDs and
evidence remain traceable; accepted items outside group 1 are not release blockers.

Current implementation: **N1 and N4 before release**, explicitly requested by the
owner. Existing tested behavior stays in place. The [N1/N4 pass](reviews/2026-11-24-n1-n4.md)
passed 98 fast checks and 43 relevant isolated DB checks. The earlier
[hardening pass](reviews/2026-11-24-parallel-hardening.md) additionally covered vector
compatibility. This is not final release sign-off. Hosted CI, cold setup, combined live E2E, aligned Desktop
and real restricted-user onboarding evidence remain pending.

See [roadmap](ROADMAP.md), [release checklist](RELEASE_CHECKLIST.md), and
[simplification decisions](reviews/2026-11-24-se-simplification.md).
