# INGEST-001 fix evidence

Date: 2026-09-10

Status: complete

## Root cause and containment

The pinned external data-modeling package generates compatibility drafts rather
than executable workspace-safe queries: node drafts discard
`source.column_name`, and relationship drafts can omit a relationship variable
and write relationship properties to the end node. The local ingest server
previously accepted those drafts without an owned compilation boundary.

The ingest package now owns a deterministic compiler exposed as
`compile_node_ingest_query` and `compile_relationship_ingest_query`. It resolves
declared CSV source columns, validates all dynamic identifiers, resolves endpoint
keys from the data model, binds the relationship, and writes properties only to
the intended graph element. The coding-agent skill now requires this compiler
before `ingest_csv_into_neo4j`.

## Remaining boundary

`ingest_csv_into_neo4j` remains an arbitrary-Cypher compatibility executor. The
skill no longer routes generated model queries directly into it, but replacing
arbitrary query execution with a declarative, bounded ingestion plan belongs to
the already-tracked `PERF-001` and broader write-safety work.
